STEP assemblies (AP214, millimetres, Z up), one per portfolio project.
Each file opens in SolidWorks, Onshape, Fusion 360 or FreeCAD as a multi-part assembly
with named, colored parts.

These are parametric reconstructions built from the project descriptions,
not Tashvi's original design files.
The Li-S pack follows her retention-concept CAD; everything else is representative geometry.
